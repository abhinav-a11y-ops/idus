Technical Architecture

Frontend Stack

React 19 with Tailwind CSS 4, TypeScript, and modern UI components. Responsive design with dark theme.

Backend Stack

Express.js with tRPC for end-to-end type safety. Secure API proxies for all external services.

Database

MySQL/TiDB with Drizzle ORM. 10 core tables for users, subscriptions, credits, and generations.

Deployment

Netlify with autoscaling, global CDN, and 99.9% uptime. Automatic builds and deployments.

Authentication

Manus OAuth for secure user authentication. JWT tokens for session management.

Payments

Razorpay for recurring subscriptions. Multiple payment methods: cards, UPI, wallets, net banking.
